# Torro Del' Alvaro — Multipage Store

Development branch for converting the existing landing page into a structured online store.

## Planned structure

- `/` — Home
- `/catalog.html` — Full fragrance catalog
- `/product.html` — Product detail template
- `/about.html` — Brand story
- `/contact.html` — Contact and ordering

## Store features

- 10-fragrance collection
- Individual product pages
- Price and fragrance notes
- WhatsApp ordering flow
- Responsive navigation
- SEO titles, descriptions and structured product data
- Existing Torro Del' Alvaro visual identity retained

## Deployment safety

Development is isolated on `store-development`. The live `main` branch is not modified until the new store is reviewed.
